This can easily be modified to work with regular links as well. It may do so already, I have not tested it.

Usage:

1. Open Chrome Browser
2. Navigate to home page of your NotebookLM project
3. Press F12, open "Console" at the top of window that appears
4. Click next to the > to type in console, write "allow pasting"
5. Paste the script from batch.js
6. Add YouTube links and wait. 

You can shorten the delays to make it faster if u want to, i have not tested how low u can go, if u go too fast some links will not add correctly

This will not be maintained, it currently works as of April 30 2025
